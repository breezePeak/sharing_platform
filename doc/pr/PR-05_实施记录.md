# PR-05 实施记录

日期：2026-11-16。工程保持 JDK 11、Spring Boot 2.7.18、JPA 和直接连接 PostgreSQL。PR-05 是开发计划编号，不代表已创建远端 PR。

## 实现

- 统一 JSON 任务入口开放 PULL；新增受控 `sourceId` 配置，固定来源、连接修订、就绪/单元规则、目标根、接收方、通知 URL 和访问映射快照。单次任务不创建监听。
- 完整成功扫描后固定本次任务单元范围；发现时先登记候选，只有完整观察累积稳定次数。文件或集合改变重置观察；未就绪单元不阻塞其他单元。源文件及其中间父目录尚未出现时，原任务保持等待，检查不越过配置的读取根。
- PostgreSQL 交付唯一键、当前轮次和任务关联保证不同 taskId 可共享一个下载/通知。键区分消费方、落地根/映射、单元规则与校验要求；拒绝的同一业务数据不会反复下载。
- 在 `tmp/transferId/` 下载固定集合，实际落盘核对大小并流式 SHA-256。BASIC 与 HASH 分开，HASH 必须有绑定源版本的清单基准。FTP/SFTP 适配器新增可空修改时间；弱识别不足时保持待来源，而非伪造可靠版本。
- 下载前后复核源；基准变化使旧轮次 SOURCE_CHANGED，重回候选，保留历史。强清单版本不变但观察基准变化也可在重新就绪后进入新轮次。普通网络错误最多 4 次，原 transferId 保留，未完成文件整文件重下，已核验的临时文件可复用。
- 发布前保存意图、清单和实际摘要，优先原子移动；复制回退仅在 `.sharing-complete` 最后写入后才对业务有效。恢复可在源服务离线时核对本地成果并补齐发布事实/通知。已有有效标记的数据损坏时保留现场，不覆盖。
- 复用原任务执行池、领取/心跳、通知 Outbox 和通知发送器。发布事实及固定通知同事务；通知失败只补通知。业务和控制文件分别计数；失败通知不带有效位置/已通过等级。
- 新增认证 JSON 验收接口；有效验收无需等待通知 ACK。重复回执幂等、冲突落库后返回 409、伪造接收方拒绝，旧轮次只记历史。全部单元 ACCEPTED 才整单成功，超时保持 PENDING 并记提醒时间。技术失败的整单验收保持 NOT_STARTED，只有真实业务拒绝才汇总 REJECTED。
- 提供无公开 HTTP 入口的 `PullProcessor.redeliver`，要求修复说明、复核原源基准、原子切换轮次并保留关联。验收后不删除、移动或覆盖成果。

## 文件与升级

核心新增 `PullSettings`、`PullStore`、`PullProcessor`、`PullConfirmationController` 和 `V5__pull_deliveries.sql`；任务、查询、通知错误输出和协议修改时间能力在原组件补齐。持久化使用 JPA `EntityManager` 原生语句及同一个事务管理器，不另建 JDBC 数据访问实现或第二套任务执行器。

V5 新增来源修订、候选、交付轮次、交付唯一键、任务关联、逐文件检查及回执记录。V1—V4 未改写；工作区同步进行的 PUSH 修复另用生产 V6，测试专用元数据升级顺延 V7，不打入应用 JAR。同步 PUSH 的构造器测试适配、排序测试排除英文 POSIX 规则；这些属于保持当前工作区可编译和回归的必要兼容。

用户已有 CSS、模板、图片及同工作区 PUSH 修复保留。未执行提交、推送、创建远端 PR 或部署。

## 配置、回退与边界

完整 YAML、清单、通知、查询和回执示例见 [任务接口契约](../contracts/transfer-api.md#pull-来源配置与源清单)。来源配置的 `caller-ids`、接收方 endpoint 授权、`localTargetRef`、实际根目录及 HTTP(S)/SMB 映射必须一致；BASIC 没有源清单时仍是弱识别。正式业务平台的数据可达性、源完成信号、通知 ACK 与回执语义仍需外部联调。本地测试不证明对方系统已支持。

完成标记消费规则必须由接收端遵守。未配置结构规则不解压或检查业务内容；业务验收由接收方完成。本轮只提供来源外置配置和接口查询，页面及周期监听分别留给后续 PR。下载进度按整文件持久化，未提供大文件流内实时进度；验收超时提醒先持久化为查询可见记录，未增加短信/邮件告警通道。

回退仅关闭 `platform.pulls.intake-enabled=false`。保留迁移、交付目录、来源/交付历史、查询、通知和验收；不关闭处理器，不删除已发布待验收数据，不直接启动无法识别新状态的旧执行器。

## 建议 PR 文案

标题：`feat: support one-shot pulls with verification and acceptance receipts`

正文：统一任务入口支持 FTP/SFTP 单文件、目录和受控范围单次拉取，持久化候选/源版本并通过 PostgreSQL 唯一键复用同一交付。固定集合下载后执行 BASIC/HASH、源前后复查和可恢复发布，复用通知 Outbox；认证验收支持先于 ACK、幂等/冲突及轮次保护，整单仅在全部单元验收成功后完成。新增 V5 增量迁移与真实 PostgreSQL、双协议和 HTTP 验收；本地验证数量与结果以上述最终实测为准，外部业务映射及协议待联调。
