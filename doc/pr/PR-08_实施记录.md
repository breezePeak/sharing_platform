## 回归命令与环境

在 `sharing_platform` 下运行 `mvnw.cmd -B clean verify`，配置隔离 PostgreSQL 的 `TEST_DB_URL`、`TEST_DB_USERNAME`、`TEST_DB_PASSWORD`，以及 `TEST_BROWSER_EXE` 和 `TEST_PG_BIN`。JavaScript 回归使用 `node src/test/js/task-refresh.test.cjs`。测试连接、回调账号和目录均为本机隔离夹具。

2026-11-19 完整 Maven 验证通过。44 项单元及页面/协议测试和 122 项集成测试均通过，0 项跳过。Chrome 桌面任务页面与 JavaScript 刷新脚本验证通过。

本次本机构建包为 `sharing_platform/target/sharing-platform-pr8.jar`。SHA-256 为 `ebba094e7eeaa58c21c4f6b843ea1461b056f1ec36b3d07ee94fa8e6379e52f4`。

关键版本为 Java 11.0.28、PostgreSQL 13.23、JDBC 42.7.14、Flyway 8.5.13 和 Boot 2.7.18。容量测试测量单工单连接的传输样本，结果不用于承诺生产吞吐或大于 2 GiB 的文件边界。
