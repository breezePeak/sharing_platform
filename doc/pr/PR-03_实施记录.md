# PR-03 实施记录

## 已实现

- 新 JSON 接入、任务查询及文件分页接口；Bearer 调用方配置、endpoint 授权、受控路径校验、请求上限和错误码。
- PostgreSQL V3 增量迁移：任务、产品、通知。`(caller_id, external_task_id)` 唯一约束配合 `ON CONFLICT DO NOTHING`，同号重放复用原 endpoint 修订和通知地址快照。
- 固定大小执行器、数据库条件领取与领取身份栅栏、心跳、重试时间；阶段结果与通知在同一事务提交。线程池满时任务保留在数据库。
- 通知条件领取、固定编号与报文、JSON/XML 关联 ACK、有限退避和 `NEEDS_ATTENTION`。预检通知 ACK 后同任务进入下一阶段。
- 暂定 XML 适配与样例，默认关闭；测试处理器只在 `TaskCoreIT` 中装配。生产 PUSH/PULL 新任务返回 503，不会形成无人执行的任务。
- 接口和暂定 XML 详见 `doc/contracts/`。旧测试迁移 `V3__test_metadata_upgrade.sql` 改为 V4，避免与业务 V3 版本冲突。
