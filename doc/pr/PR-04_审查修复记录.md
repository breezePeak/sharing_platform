## 实际删除与替换

- 删除 PushProcessor 的 JdbcTemplate import、字段、构造参数、直接 SQL、TransactionTemplate；原 records/directories SQL 映射和内部 FileRecord 被实体/仓储替代，Snapshot 只保留源文件本地校验职责。
