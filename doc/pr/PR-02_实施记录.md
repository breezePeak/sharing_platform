# PR-02 实施记录

日期：2026-11-13。基于本地 `a695f0c`（PR1）实施，沿用 Java 11、Spring Boot 2.7.18、JPA、原生 PostgreSQL、无登录 / 无 Spring Security / 无 Docker。修改留在工作区，不提交、推送、创建或合并远端 PR。

## 交付范围

- `/config` 转向 `/config/endpoints`：连接列表、新增 / 编辑、启停、独立确认清除凭据、异步能力检测，沿用现有导航与 CSS。
- V2 增量创建连接、不可变配置 / 凭据版本、检测记录及操作记录。旧版本始终保留，未来任务应固定引用 `endpoint_revision.id`。编辑后旧检测明确标为过期；并发编辑按版本拒绝，网络操作不持有数据库事务。
- 密码 / 私钥口令用外置 32 字节主密钥进行 AES-256-GCM 加密，以配置版本 ID 作为 AAD。表单留空保留原值；页面不接收数据库秘密字段、不回显原文或密文。明确清除会创建不含当前密码 / 私钥引用的版本，不删除历史版本或外部文件。
- 私钥只能引用管理员受限目录中的文件名，拒绝路径越界、符号链接 / Windows 目录联接及特殊文件；保存时固定文件 SHA-256，文件被替换则拒绝连接。支持服务器配置的本地根目录引用，不能由表单任意读取系统目录。
- 小型 `RemoteFileClient` / factory：列举、lstat、流式读写、创建目录、改名、临时清理、路径能力及容量查询、关闭。单次执行独占会话，不依赖远端 shell。
- FTP 二进制、默认被动 / 可选主动；流结束后检查最终完成响应，数据流或完成阶段异常关闭会话，避免后续命令错位。SFTP 必须精确匹配预配 SHA256 主机指纹，不自动信任，不加载本机 SSH 配置或默认身份。
- 读取指定非空测试对象；只在明确授权且已存在的探测子目录创建独占随机目录，写 4096 字节随机数据、实际大小 / 全量回读 SHA-256、改名、非递归清理。只读合法，不能回读的只写连接不通过严格推送条件。
- 检测全局并发 2、无排队缓冲，并遵守每连接上限；忙时 429。单阶段 1—30 秒，总时限为 6 倍。操作前落库可能残留路径，总超时关闭活动会话且阻止迟到写回，重启将运行中记录改为 `INTERRUPTED`。
- 会话 CSRF、表单字段白名单、Bean Validation、协议 / 目录交叉校验、输出转义、16KB 容器表单限制。无新增业务任务 API、监听、通知或登录框架。

## 迁移与回退

## 边界与未验证项

- FTP 无法可靠识别全部远端链接，必须由管理员提供隔离账号根目录，页面明确标为有限路径保证。不支持可靠属性查询的服务器会拒绝 / 报告无法验证，不声称严格路径验证通过。
- SFTP 的 lstat 是检查时的服务器属性，不承诺对恶意服务器或共享目录并发替换路径的原子保护。私钥目录与远端探测子目录须受管理员控制；平台独占随机探测目录，不写既有业务文件。
- Windows 当前令牌没有创建文件符号链接的权限。本地使用真实 NTFS 目录联接验证拒绝；远端链接测试明确是 SFTP 服务端属性故障注入，并非本机真实 Unix 符号链接文件。未将此描述为真实 Unix 链接验收。
- 容量通过实际支持的 SFTP statvfs / space-available 扩展查询，失败或无扩展为 UNKNOWN；没有可靠容量信息时不宣称空间充足。
- 未访问客户 FTP/SFTP、生产网络、HTTPS 或外部联调系统；未执行远端 GitHub Actions。真实客户权限、私钥格式 / 算法及主机指纹应在接入时验证。PR1 已记录的 Boot / PostgreSQL 版本维护风险仍适用。
- 推送 / 拉取任务、监听、XML、回调及业务验收不属于 PR2，仍未实现。本次探测不能代替未来任务预检查。
