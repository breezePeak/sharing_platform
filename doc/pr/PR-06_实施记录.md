# PR-06 实施记录

## 变更

- `/config/listeners` 支持新增、编辑、启停、手动扫描、运行记录和关联任务。来源复用 PR5 外置配置，范围或规则调整需要确认并保存修订。换名称或周期时沿用原修订。V7 增量迁移持久化监听、配置修订、扫描记录、候选起点、基线及任务关联。
- 调度器按连接与到期时间公平选择扫描，维护独立有界扫描池，满额时计划留库。用 PostgreSQL 条件领取和唯一索引保证每个监听最多一个有效扫描。租约过期后将旧扫描标记为中断并合并补扫，初始化和去重历史继续有效。
- 完整扫描才会更新稳定次数和缺失状态。上游标记与清单优先，稳定观察默认至少三次并跨 120 秒。`BASELINE_ONLY` 原子登记首次完整扫描所见的版本，基线范围随监听和实际交付键约束。
- 手动扫描、定时扫描和 API 共用候选、版本与交付逻辑。重复版本复用现有任务和交付记录，PR5 历史交付可归入同一规范化交付键。就绪后由 PR5 执行器下载、校验、发布、通知及验收。在任务池中按连接交替优先处理已到期任务。
