## 数据库、迁移与回退

本机实际 PostgreSQL **13.23**，直接连接 `127.0.0.1:5432`。本次新建 `sharing_platform` 与 `sharing_platform_test`，没有改动默认 `postgres` 库。开发库现在只保留 V1 元数据和迁移历史；测试库内本次 `foundation_it_*` schema 已全部清理，核对剩余数为 0。未创建或清理任何业务传输数据目录。

配置与运行方式见 README。V1 创建 `platform_metadata` 并写入平台名称，JPA 改造未修改该 SQL，不需要删表或重建库。通过实体与 JpaRepository 读写，Hibernate ddl-auto=validate、open-in-view=false；结构由 Flyway 管理，禁止 Hibernate 自动更新和 Flyway clean。回退代码保留数据库与历史；此前 V1 数据兼容。

CI 使用 Ubuntu 原生编译并启动固定 PostgreSQL 13.23，不使用 Docker，不连接本机/客户数据库；随机生成测试密码，执行相同 `clean verify`。未授权推送代码，故没有触发 GitHub Actions；不能将本地通过表述为远端 CI 已通过。Unix Wrapper、Ubuntu 原生 PostgreSQL 编译及生产 HTTPS/外部网络部署未在本机 Windows 实测。

JDK 11 是用户要求，Boot 2.7.18 是为其选定的旧兼容版本，已经结束开源维护；PostgreSQL 13 也已结束官方支持。页面按要求无登录，应限制网络访问范围。这些版本与部署风险需在正式投产前处理，不能将本地基础验收等同于生产验收。
